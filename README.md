# Algorithm

코딩 테스트 준비용 풀이 모음. 하루 한 문제씩 쌓는 곳.

## 규칙

- **하루 1문제.** 오전 11시 슬롯에서 푼다. 저녁으로 미루면 안 하게 된다.
- **30분 룰.** 30분 안에 접근법이 안 나오면 알고리즘 분류만 확인하고, 45분에 해설을 본다.
  실제 코테도 문제당 30~40분이라 이게 연습이 된다.
- **제출 전 반례 3개.** 최소 입력 / 최대 입력 / 답이 0이나 음수인 경우를 먼저 종이에 적고,
  기대값을 손으로 계산해둔 다음 돌려서 비교한다. 통과는 증거가 아니다.
- **한 번 푼 문제는 다음 날 다시 짠다.** 신규 세 개보다 재풀이 한 개가 더 남는다.
- **문제를 고르지 않는다.** 리스트를 정해두고 위에서부터 내려간다.
  고르는 행위 자체가 오전 슬롯을 잡아먹는다.

## 파일 이름

```
leetcode/0206_reverse_linked_list.py
leetcode/0206_reverse_linked_list.c
```

번호 네 자리 + 스네이크케이스. 번호를 0으로 채워 쓰면 정렬이 알아서 맞는다.
같은 문제를 다른 언어로 다시 풀면 확장자만 바꿔서 나란히 둔다.
